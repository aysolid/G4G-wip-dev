# G4G Research Operations - User Guide

## Getting Started

### Accessing the Application

1. Open the web app URL provided by your administrator
2. You will see the public dashboard with overall study statistics
3. Click **"Staff Login"** to access the full application

### Logging In

1. Enter your email address
2. Enter your password
3. Click **"Sign In"**

If you're having trouble logging in:
- Verify your email is correct
- Check that Caps Lock is not enabled
- Contact your administrator for a password reset

---

## User Roles

### Admin
Full access to all features:
- Manage users (create, edit, reset passwords)
- Create and manage study rollouts
- Enroll participants
- Update checklists
- View all sites
- Export data

### Facilitator
Data collection and participant management:
- Enroll new participants
- Update checklist items
- Add notes
- View participants (own site by default)
- View reports

### Viewer
Read-only access:
- View dashboards
- View participant details
- View reports
- Cannot modify any data

---

## Dashboard

The dashboard provides an at-a-glance view of the study's progress:

### Statistics Cards
- **Total Participants**: Number of enrolled participants
- **Active Participants**: Currently active in the study
- **Avg Completion**: Average checklist completion percentage
- **Active Cohorts**: Number of ongoing study rollouts

### Protocol Checklist Progress
Shows completion rates for each of the 18 required instruments:
- Green bars: High completion (80%+)
- Yellow bars: Medium completion (50-79%)
- Blue bars: Low completion (<50%)

### Site Comparison
Compare participant counts and completion rates between UGA and Missouri.

### Quick Actions (Admin/Facilitator)
- Enroll Participant
- Update Checklist
- New Rollout (Admin only)
- Add User (Admin only)

## Managing Participants

### Viewing Participants

1. Click **"All Participants"** in the sidebar
2. Use the search box to find specific participants
3. Click **"View"** to see participant details

### Enrolling a New Participant

1. Click **"Enroll New"** in the sidebar (or dashboard)
2. Fill in the form:
   - **Full Name**: Participant's full name
   - **Site**: Select UGA or Missouri
   - **Study Rollout**: Select the appropriate cohort
   - **Notes**: Optional additional information
3. Click **"Enroll Participant"**
4. The system will generate a unique participant ID

### Viewing Participant Details

The participant detail page shows:
- **Left Panel**: Participant information
- **Right Panel**: 18-item protocol checklist

### Updating the Checklist

For each instrument, you can:
- **Mark Complete** (green checkmark): Item has been collected
- **Mark Missing** (red X): Item is missing or unavailable
- **Add Note** (note icon): Add additional context

Status indicators:
- ✓ Green circle: Completed
- ! Red circle: Missing
- Number: Not started

---

## Study Rollouts (Admin Only)

Study rollouts represent cohorts or sessions of the study.

### Creating a Rollout

1. Go to **"Study Rollouts"** in the sidebar
2. Click **"Add Rollout"**
3. Fill in the form:
   - **Site**: UGA or Missouri
   - **School/Location**: Name of the school or location
   - **Period**: Spring, Summer, or Fall
   - **Year**: The year (e.g., 2025)
   - **Description**: Optional description
4. Click **"Save Rollout"**

### Managing Rollouts

- View all rollouts in the table
- Edit rollout details using the edit button
- Change status (active, completed, cancelled)

---

## User Management (Admin Only)

### Creating a User

1. Go to **"User Management"** in the sidebar
2. Click **"Add User"**
3. Fill in the form:
   - **Full Name**: User's display name
   - **Email**: Login email address
   - **Role**: Admin, Facilitator, or Viewer
   - **Site**: All Sites, UGA, or Missouri
4. Click **"Create User"**
5. A temporary password will be displayed - share it securely with the user

### Resetting a Password

1. Find the user in the user list
2. Click the lock icon next to their name
3. Confirm the reset
4. Share the new temporary password securely

## Exporting Data

### Available Exports

1. **Participants Export**: CSV file with all participant data
2. **Checklist Export**: CSV file with all checklist items
3. **Summary Report**: Text file with cross-site summary

### How to Export

1. Go to **"Export Data"** in the sidebar
2. Click **"Export"** next to the desired report type
3. The file will download automatically

### Export Contents

**Participants CSV includes:**
- Participant ID
- Full Name
- Site
- School/Location
- Period/Year
- Enrollment Date
- Status
- Completion %
- Notes

**Checklist CSV includes:**
- Participant ID
- Participant Name
- Site
- School
- Instrument Number
- Instrument Name
- Category
- Status
- Completed Date
- Completed By
- Notes

## Troubleshooting

### Can't Log In

- Verify email address is correct
- Check Caps Lock status
- Request password reset from admin
- Clear browser cache and try again

### Page Not Loading

- Check internet connection
- Refresh the page
- Try a different browser
- Clear browser cache

### Data Not Saving

- Check internet connection
- Wait a moment and try again
- Refresh the page
- Contact your administrator

### Export Not Working

- Allow pop-ups for the site
- Check download folder
- Try a different browser
